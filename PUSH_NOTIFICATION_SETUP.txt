i.S WHOLESALE COMMUNICATION — PUSH NOTIFICATION SETUP

यह ZIP में जोड़ा गया Push Notification फीचर है। SMS या टेक्स्ट मैसेज का कोई उपयोग नहीं है। फोन पर वेबसाइट के लोगो के साथ Chrome/वेबसाइट Push Notification आएगी। यह सेटअप एक बार Firebase/Netlify पर करना जरूरी है; केवल ZIP अपलोड करने से वास्तविक Push शुरू नहीं होगा।

इसमें तय तीन घटनाएँ:
1) customerOrders/{shopUid}/{orderId} पर नया ऑर्डर बनते ही दुकानदार के सभी opted-in फोन पर: “आपकी वेबसाइट पर एक नया ऑर्डर आया है।” (Pay By/online और COD दोनों)
2) दुकानदार dashboard से confirmed=true करे तो उसी ऑर्डर वाले ग्राहक के opted-in फोन पर: “डिलीवरी कन्फर्म।”
3) पहले से प्रकाशित आइटम/नोटबुक लिस्ट दोबारा अपडेट/शेयर होने पर, उस लिस्ट को पहले खोल चुके और Push चालू कर चुके ग्राहकों को नई लिस्ट की सूचना।

A. Firebase Web Push public key
1. Firebase Console → Project Settings → Cloud Messaging.
2. Web Push certificates में Generate key pair करें.
3. Public key कॉपी करें.
4. आपकी दी हुई Web Push Public Key अब index.html में जोड़ दी गई है। इसे दोबारा बदलने की जरूरत नहीं है।

B. Firebase Cloud Functions deploy (Blaze billing plan जरूरी हो सकता है)
1. अपने कंप्यूटर पर Firebase CLI install/login करें: npm install -g firebase-tools ; firebase login
2. इस ZIP को extract करके उसी folder में terminal खोलें.
3. firebase use i-s-wholesale-communication
4. cd functions && npm install && cd ..
5. firebase deploy --only functions
   Functions asia-south1 region में deploy होती हैं. Firebase Realtime Database → Data/Settings में database की location भी देखें; यदि वह asia-south1 नहीं है, तो functions/index.js में तीनों जगह region value को उसी database location से बदलकर deploy करें.

C. Realtime Database rules
1. Firebase Console → Realtime Database → Rules खोलें.
2. मौजूदा rules को replace न करें.
3. PUSH_DATABASE_RULES_ADD.json के अंदर दिए pushTokens और publicListSubscribers blocks को मौजूदा top-level rules में अलग-अलग children के रूप में जोड़ें.
4. मौजूदा customerOrders, customerNotifications, users, publicLists और customerCarts rules को जस का तस रखें.
5. Publish करें.

D. Hosting
1. index.html, logo.jpg और firebase-messaging-sw.js को Netlify site की root/publication directory में रखें.
2. firebase-messaging-sw.js को https://is-wholesale-communication.netlify.app/firebase-messaging-sw.js पर सीधे खुलना चाहिए (404 नहीं).
3. Site HTTPS पर होनी चाहिए.

E. फोन पर अनुमति
1. दुकानदार अपने फोन में वेबसाइट Chrome में खोले, लॉगिन करे और “फोन पर नोटिफिकेशन चालू करें” दबाकर Allow करे.
2. ग्राहक shared list अपने फोन में खोले, वही बटन दबाकर Allow करे. ग्राहक को उसी सूची के future re-share alerts मिलेंगे.
3. ग्राहक/दुकानदार के एक से अधिक opted-in devices हों तो सभी पर notification जा सकती है.

महत्वपूर्ण सीमाएँ/व्यवहार
- ग्राहक को re-share notification तभी मिल सकती है जब उसने उस सूची को पहले खोला हो और उस फोन पर Push Allow किया हो; दुकानदार WhatsApp पर link किसे भेजता है यह वेबसाइट अपने आप नहीं जान सकती.
- Browser/Android notification permission बंद, battery/data restrictions, unsupported browser या Firebase Functions setup न होने पर notification नहीं आएगी.
- Online payment का payment-success verification इस feature में नहीं जोड़ा गया; मौजूदा flow में जैसे ही order customerOrders में save होता है, owner notification भेजी जाती है.
- यह server-side push है; SMS, WhatsApp message या email नहीं भेजता.
